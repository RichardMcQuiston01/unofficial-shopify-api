# Security Policy

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private
[security advisory](https://github.com/RichardMcQuiston01/unofficial-shopify-api/security/advisories/new)
form, or email richard.mcquiston@gmail.com. Expect an acknowledgement within
a few days.

## Scope

This library handles Shopify access tokens, OAuth callbacks and webhook
signatures. Reports about token leakage, signature-verification bypass or
unsafe defaults are especially welcome.
